# Technical Writing

## When to Use This Skill
- Writing user guides, API references, or tutorials
- Structuring documentation for scanning and comprehension
- Choosing the right level of detail for the audience
- Creating tutorials that teach, not just demonstrate

## Workflow
1. Identify the audience: beginner, intermediate, or advanced
2. Structure the content: title, overview, steps, examples, and next steps
3. Write for scanning: headers, bullet points, short paragraphs, code blocks
4. Add code examples: complete, runnable, and tested
5. Explain the "why" alongside the "how"
6. Review for clarity: can someone follow this without prior context
7. Test: have someone follow the docs and note where they get stuck

## Rules
- Start with what the user wants to accomplish, not what the tool does
- Use active voice and imperative mood for instructions
- Keep code examples minimal but complete — they should run
- Explain terms before using them — don't assume prior knowledge
- Include expected output for every code example
- Update docs when the code changes — stale docs are worse than no docs
